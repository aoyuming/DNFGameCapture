# death_x_dynamic_tolerance_patch

本补丁只修改 `DNFGameCaptureDlg.cpp` 里的死亡大 X 颜色检测逻辑。

## 修改点

1. 中心点仍然保持严格红橙色检测。
   - 中心附近必须有接近死亡 X 基准色 `#D53000` 的红橙像素。
   - 白色高光、黄色边框、红色底板不能单独通过中心。

2. 四条斜边改为“按距离动态容差”。
   - 离中心近：仍按严格红橙色判断。
   - 离中心越远：允许 X 笔画变暗，但仍要求保持红橙色相。
   - 只对 X 斜边射线生效，不全局放宽红色检测。

3. 四个方向改成积分制。
   - 严格红采样点：+2 分。
   - 远端动态弱红采样点：+1 分。
   - 主将大 X 每个方向必须满足：方向分 >= 3、至少 1 个严格红点、远端有红/弱红证据。
   - 最终仍然是中心通过 + 四方向至少 3 个方向通过，才算死亡 X。

## 目的

解决主将大 X 下边两条边越往外越暗，导致明明 X 很明显但检测方向数不够的问题。

## 替换方式

把本补丁里的 `DNFGameCaptureDlg.cpp` 替换到项目对应文件后重新编译。
