# Web 小号重复添加修复补丁

本补丁修复 Web 端小号列表重复显示 / 重复写入的问题。

## 修改点

1. 新增 Web 端小号去重函数 `uniqueAliasArray()`。
2. 以下位置都会自动去重：
   - 从 C++ 接收 `fullAliasDB` 时；
   - 从 C++ 接收场上 8 个选手的小号列表时；
   - 添加小号时；
   - 修改小号名时；
   - 渲染小号弹层前；
   - 同步回 C++ 前。
3. 如果用户重复添加同一个小号，Web 会提示“小号已经存在，不会重复添加”。
4. 仍然保留现有规则：
   - 允许小号列表存在 2 字短 ID；
   - 2 字裸短 ID 只在开始监控时拦截；
   - 修改小号名时，会同步修改当前选手列表和永久库。
