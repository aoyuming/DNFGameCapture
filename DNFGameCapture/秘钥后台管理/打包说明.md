# DNF 共享库管理台打包说明

## 方案 A：打包成本地 exe

这个方案最省改动：exe 内置 Node 运行时，使用者电脑不需要安装 Node。

### 网页管理台 exe

在开发电脑上执行：

```powershell
Set-Location 'C:\Users\BRO\source\repos\DNFGameCapture\DNFGameCapture\秘钥后台管理'
npm.cmd install
npm.cmd run build:web-exe
```

生成文件：

```text
秘钥后台管理\dist\dnf-capture-admin-web.exe
```

发布时把下面两个文件放在同一个目录：

```text
dnf-capture-admin-web.exe
admin.config.json
```

`admin.config.json` 不要打进 exe，里面有 OSS AccessKey。可以从 `admin.config.example.json` 复制一份后填写。

启动：

```powershell
.\dnf-capture-admin-web.exe
```

默认地址：

```text
http://127.0.0.1:8899
```

如果端口被占用：

```powershell
$env:ADMIN_WEB_PORT='8898'
.\dnf-capture-admin-web.exe
```

### 命令行管理台 exe

在开发电脑上执行：

```powershell
Set-Location 'C:\Users\BRO\source\repos\DNFGameCapture\DNFGameCapture\秘钥后台管理'
npm.cmd install
npm.cmd run build:cli-exe
```

生成文件：

```text
秘钥后台管理\dist\dnf-capture-admin-cli.exe
```

发布时把下面两个文件放在同一个目录：

```text
dnf-capture-admin-cli.exe
admin.config.json
```

启动：

```powershell
.\dnf-capture-admin-cli.exe
```

如果两个版本都要打：

```powershell
npm.cmd run build:all-exe
```

## 方案 B：做成纯网页

不要把 OSS AccessKey 写进网页。浏览器里的 JS 会被任何人看到，密钥泄露后别人可以改/删整个 Bucket。

纯网页方案需要改成：

1. `web-admin` 页面部署到 OSS 静态网站或任意网页服务器。
2. 管理 API 搬到云函数。
3. 云函数用管理员 CDK 或密码校验身份。
4. 网页只调用云函数，不直接连接 OSS。

这个方案用户体验最好，但需要把 `admin-web.js` 里的 `/api/dashboard`、`/api/review`、`/api/public/*` 迁移到 `云函数/index.js`。
