# 5.5.3 · LOL前导提示声修复 r1

此包替代此前的 `DNF-5.5.3-Streamer-Tools.zip`，版本仍为5.5.3。本次没有付费语音生成调用；没有自动替换现用EXE或部署正式服务器。

## 音频修复

- 7段LOL素材逐条定位裁剪，28个台词槽位复用这7段修订音频。移除了前导网站人声/提示音，而不是统一截掉固定秒数。
- 双杀0.76秒、三杀0.96秒、一血1.38秒、终结1.19秒、复仇替代1.94秒、Ace 1.35秒、胜利1.77秒起保留。
- 裁剪边界加入6毫秒淡入，后续PCM样本与原音频对应部分完全相同，完整保留尾音。原始文件备份保留在开发机 `build/lol-clean-verify/original-voice/`。
- 波形和离线ASR检查了切点与保留的词句；短促Ace的识别结果有歧义，不能把ASR当作真人听感验收。已附单独试听文件，顺序为双杀、三杀、一血、终结、复仇替代、Ace、胜利。
- 复仇仍用 “You have slain an enemy” 代替。来源、原哈希、裁剪参数、新哈希保留在 `docs/lol-announcer-sources.json` 和 `docs/lol-clean-edits.json`。这是下载素材的剪辑版，不宣称是重新录制或获得了版权许可；原权利人及使用授权注意事项不变。
- 四个TTS音色共112个文件保持逐字节不变。

## 默认设置

- 默认选项0现在为 **默认（LOL音效播报）**，按稳定ID `lol-announcer` 查找，不假定LOL一定是编号6。其他音色编号不改变。
- 所有9种展示风格默认使用LOL；仍可手动选择其他音色，风格化TTS话术保留。
- **首次使用：语音播报关闭、全屏特效关闭。** 选择音色不等于开启播放。
- **恢复默认：同时关闭语音与全屏，音色回到LOL默认。** 展示窗口的显示状态不改变。
- 已有用户手动保存的音色、开关选择不被升级强制重置；如果此前已手动开启，请在主播工具中关闭或点击恢复默认。

## 更新顺序

1. 先按本修订随附的新脚本更新服务器及音频，原环境配置、业务数据库和授权数据保留。不要使用此前绑定旧ZIP哈希的脚本，也不要用通用 `--replace` 覆盖所有声音。
2. 退出客户端、备份后，用 `client-update/` 同名文件更新现有安装。保留原配置和其他运行依赖。本包不是全新安装器。
3. 若曾开启播报，新目录/音频哈希会使缓存更新；旧音频文件可留在哈希缓存，不需要清空整个缓存。客户端约一分钟复查目录。未勾选播报时不下载音频。
4. 选默认LOL，确认语音/全屏开关仍处于期望状态；需要试听时再手动开启。若仍听到旧提示声，先核对服务器目录的LOL音频哈希是否为本包的新哈希，而不是反复生成。

## 安全的离线导入

服务器CLI新增 `--repair-lol` 和 `--only-lol`。升级已有音频库时：

```sh
node dist/import-voices.js --from /absolute/import/voice --only-lol
node dist/import-voices.js --from /absolute/import/voice --database /absolute/existing/cloud-match.sqlite --apply --repair-lol --only-lol
```

只允许把28个已知旧LOL哈希换成对应已知新哈希。不同的自定义LOL音频会使整批事务回滚并报错；其他音色不被改动。重复执行复用相同哈希，旧音频版本保留在数据库中，不调用TTS。首次导入空音频库时可去掉 `--only-lol` 导入140个槽位；同样无需生成。

配套升级脚本针对已确认的正式服 `/opt/dnf-cloud-match-server` 与数据库 `/var/lib/dnf-cloud-match/cloud-match.sqlite`。只在现有TTS槽位为空时首次导入全部140个槽位；已有TTS时只修复LOL。依赖准备/校验在停服前完成，输入UPGRADE后才停服备份升级，失败时尝试安全回退。测试服、PM2、防火墙和环境配置不修改。
