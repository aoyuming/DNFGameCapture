# 服务器端主播归属关联设计

**日期：** 2026-09-13
**发布版本：** 服务器包 5.2.3；本地客户端保持 5.2.2

## 目标

在不修改已安装客户端的前提下，把选手库投稿和已激活密钥关联到主播身份。管理后台需要显示投稿来源主播、密钥使用主播、主播 IP 与地区，以及主播对应的完整可恢复密钥。

## 约束

- 授权机器码与 Socket.IO 主播设备 ID 是现有系统中的两套独立身份。
- 现有客户端不会直接上报这两套身份的对应关系。
- IP 相同只能作为辅助证据，不能视为身份凭证；共享出口 IP 存在歧义时禁止自动关联。
- 现有客户端和数据库必须继续兼容，不要求人工执行数据库迁移命令。
- 密钥明文不得进入列表接口、状态接口或日志。

## 归属数据模型

服务器正常启动时，以向后兼容方式自动创建三组 SQLite 数据：

1. `license_ip_observations`：记录已认证密钥、授权机器码、规范化公网 IP，以及最近一次认证 HTTP 活动时间。
2. `broadcaster_network_observations`：记录每个主播设备最近一次规范化 IP、解析地区和观察时间。
3. `broadcaster_license_links`：记录每个主播设备当前对应的密钥，包括授权机器码、最后已知主播名、关联来源（`automatic` 或 `manual`）及时间。

每次发生已认证 v2 HTTP 活动或主播 Socket 活动后，服务器尝试自动关联。只有同时满足以下条件才会新增或刷新关联：

- 地址是公网 IP；
- 密钥活动仍在规定的短时间窗口内；
- 该 IP 下恰好只有一个授权身份和一个在线主播候选；
- 密钥仍绑定到该授权机器码；
- 不会覆盖管理员建立的人工关联。

地址存在歧义、属于内网或回环地址、格式无效、记录过期时均保持未关联。人工关联始终优先，自动逻辑永远不能覆盖。

## 人工关联

主播详情增加已激活密钥选择器。管理员可以为当前主播绑定密钥或更换密钥。写接口在落库前校验主播、密钥、密钥当前绑定机器码和 CSRF 令牌，并将关联标记为 `manual`。

该功能用于处理共享网络、五天离线授权租约，以及无法自动识别的历史主播。

## 管理页面

### 选手库

待审投稿通过其授权机器码查找已验证的主播关联。列表和详情优先显示主播名称，机器码保留为次要诊断信息；搜索支持主播名称。无法关联时明确显示“未关联主播”，不得猜测。

### 密钥管理

每条密钥记录在绑定机器码旁显示已关联的一个或多个主播名称，搜索支持主播名称。密钥列表接口仍不返回明文。

### 主播管理

每条主播状态包含：

- 在线时的当前 IP；
- 持久化的最后 IP 和观察时间；
- 本地解析得到的国家、地区和城市；
- 对应密钥 ID、备注、授权机器码，以及是否存在可解密密钥；
- 关联来源（自动、人工或未关联）。

选中主播后，页面自动调用现有受保护的密钥查看接口，只解密并显示当前主播对应的一条完整密钥。只有哈希、无法恢复原文的旧密钥显示“原密钥不可用”。聚合状态接口不得包含密钥明文。

## IP 地区解析

使用随服务器安装的本地 GeoIP 数据库或依赖。查询前将 IPv4 映射 IPv6 规范化。公网地址显示能够得到的最具体国家、地区和城市；内网及回环地址显示“内网”；无法解析的公网地址显示“未知地区”。管理后台刷新时不调用任何外部定位接口。

## 数据流

1. 密钥激活、会话验证或其他已认证 v2 请求记录授权侧 IP 活动。
2. Socket 连接记录主播侧 IP 活动，并更新内存中的当前 IP 映射。
3. 归属服务只尝试无歧义自动匹配。
4. 管理状态构建器通过已存关联连接投稿、密钥和主播数据。
5. 管理员人工绑定后覆盖自动关联，并成为权威结果。

## 异常处理

- GeoIP 查询失败时显示“未知地区”，不得影响授权或主播连接。
- 归属辅助数据写入失败时，不得拒绝密钥激活、选手库同步或主播连接。
- 无效人工绑定请求以稳定错误码原子失败。
- 密钥查看继续沿用现有 `key_unavailable` 和 `vault_unavailable` 行为。
- 清理主播大厅数据时不得删除密钥记录；网络观察和失效自动关联可以单独清理。

## 验证

- 数据库迁移测试覆盖旧数据库结构及重复启动。
- 归属单元测试覆盖唯一匹配、歧义 IP、内网 IP、时效窗口、人工优先和密钥换绑。
- HTTP 与 Socket 集成测试证明旧客户端继续兼容，且服务器观察到的 IP 能形成关联。
- 管理 API 测试证明三个页面获得预期主播与网络信息，同时列表和状态 JSON 不含密钥明文。
- 管理页面测试覆盖搜索、人工绑定、选中后直接显示密钥、未关联状态、旧密钥状态以及桌面和移动端溢出。
- 发布前运行完整服务器测试、TypeScript 构建与类型检查、浏览器检查、打包校验和生产部署预检。

## 不在本次范围

- 修改本地客户端。
- 在同一个公网 IP 下存在多个用户时强行猜测。
- 在批量接口、日志、导出文件或 HTML 源码中暴露密钥明文。
- 在既没有已验证关联、也没有人工关联时，倒推出历史投稿来源。
