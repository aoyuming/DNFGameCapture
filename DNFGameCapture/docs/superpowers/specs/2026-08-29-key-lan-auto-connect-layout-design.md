# 局域网客户端自动发现与管理员续接设计

## 目标

减少局域网客户端首次连接步骤，并修复服务器模式字段相互遮挡的问题。

## 客户端流程

- 打开“局域网同步”面板且当前角色为客户端时，自动搜索一次服务器。
- 从其他角色切换到客户端时，自动搜索一次服务器。
- 发现结果优先匹配上次保存的服务器地址；没有匹配项时选择第一台服务器。
- 自动选择后立即回填服务器 IP 和端口，仍允许用户手动修改。
- 自动搜索只由打开面板或切换角色触发，不因每次状态刷新重复发起。

## 管理员重启续接

- 用户点击“连接”后，先校验并保存 IP、端口和配对码，再检查管理员权限。
- 权限不足时保存一次性待连接标记，然后执行现有管理员重启流程。
- 管理员进程启动后消费待连接标记，并使用已保存参数自动继续连接。
- 待连接标记在发起自动连接后立即清除，避免失败时循环重启或反复连接。
- 连接成功以 TCP 握手完成为准，显示绿色提示并更新面板状态。
- 连接失败或超时时显示红色原因提示，保留 IP、端口和配对码供用户直接重试。

## 服务器布局

- 服务器设置保持单行。
- 本机地址使用弹性宽度。
- 端口输入框使用约 72px 的固定窄列，只需容纳五位端口。
- 配对码使用约 96px 的独立列，标签和数值不进入端口区域。
- “重新生成”“启动服务器”和客户端状态各自使用稳定列宽。
- 在确实无法容纳完整单行的窄视口下才使用现有响应式换行规则。

## 测试

- 打开客户端面板和切换到客户端时均只自动搜索一次。
- 发现一台或多台服务器时自动选择正确项并回填 IP/端口。
- 非管理员点击连接后，配置和待连接标记在重启前已保存。
- 管理员重启后自动连接，无需重新输入或再次点击。
- 成功提示只在握手完成后出现；失败提示包含原因且不会循环重启。
- 服务器模式在常规宽度下保持一行，端口、配对码、按钮和状态无重叠。
- 前端语法、局域网静态检查、Git 空白检查和 Release x64 构建通过。
