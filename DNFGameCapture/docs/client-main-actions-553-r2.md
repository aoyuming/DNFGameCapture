# 5.5.3 客户端修订包 r2 · 按钮栏与名单提示

本包替代 `DNF-5.5.3-Client-Main-Actions.zip` 的客户端界面修订，程序版本仍为5.5.3。

## 本次修正
- 主操作按钮统一高度和间距，保留「分组和抽签」显眼入口。
- 根据操作区实际可用宽度布局：宽窗口同一排居中对齐；窄窗口上排按钮按网格完整铺开，下排开关及更多左右对齐，极窄区域采用3列网格。不再让整块辅助操作随意折到右下角。
- 分组弹窗打开时焦点落在弹窗容器，不主动刷新姓名候选。只有进入名单编辑后才显示匹配提示；移出输入框或按Esc收起，候选选择仍可用。
- 原来不在编辑名单时也能触发候选刷新，本次增加焦点和弹窗显示状态双重检查；打开、关闭再打开均保持候选隐藏。
- 分组、抽签、应用、复制、重置及原有限制保留。现有声音功能不改，未实现新增的逐事件音色绑定或新的试听列表。

## 如何更新
这是**已有客户端的更新包，不是全新安装器**。
1. 完全退出客户端并备份原程序目录。
2. 将本包 `client-update/` 下全部内容复制到原客户端目录，覆盖同名文件。
3. **EXE与`web前端/`必须一起更新**。保留原配置、数据库、语音缓存和其他运行依赖，不要删除原目录后重新解压。
4. 自行启动客户端检查新版按钮排列及打开分组时不再自动弹出的姓名提示。

本包只含客户端运行文件、说明和哈希清单。没有服务器代码、音频、私密TTS配置或部署脚本，无需上传服务器。
旧LOL修复包及其独立服务器部署流程不变，本包不执行或代替服务器修复。
本次没有生成、下载或修改音频，没有付费TTS调用。已保存的语音/全屏设置不会被强制重置。

## 验证
- Release/x64隔离构建，EXE版本5.5.3.0，未替换或启动现用程序。
- 浏览器自动化：三种主题、七种可用窗口宽度，另检查等效125%/150%缩放的逻辑视口；按钮对齐、开关行和可见范围检查通过。
- 使用预填名单和匹配候选的夹具：首次打开/重开无提示，编辑可显示及选择，失焦/Esc收起；分组、抽签和监控状态拦截检查通过。
- 客户端入口、LOL默认、主播工具、语音与左侧胜利回归通过。
- 包内 `SHA256SUMS.json` 为载荷哈希清单。真实Windows缩放/交互效果仍需更新后确认。
