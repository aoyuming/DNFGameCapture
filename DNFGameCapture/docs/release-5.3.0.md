## 本次调整

- 游戏 ID 列按最长 11 个中文字符收紧，名称别名列保留 6 个中文字符的空间。
- 别名列表位于游戏 ID 右侧，保留增删改、鼠标和键盘选择、独立滚动。

更新包：`deployment-packages/update_v530.zip`。

完全退出客户端，将更新包解压覆盖到原 `DNFGameCapture.exe` 所在目录，再打开程序。
本次改动无需重新部署服务器，无需重新激活卡密。
更新包只包含 14 个运行文件，不含配置、卡密、数据库、日志或授权租约。
