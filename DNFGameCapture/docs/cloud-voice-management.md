# 云端声音管理与客户端缓存

## 功能及费用边界

- 管理首页新增 **声音管理**，地址 `/admin/voices`，沿用原后台 Basic 认证和 CSRF 保护。管理端口仍与客户端公开端口隔离。
- 添加 TTS 音色需填写名称、唯一内部标识、豆包 speaker ID、模型资源；自定义音色无需 API 配置，按固定台词上传 PCM WAV。
- 每个音色 28 个固定台词槽位，支持试听、替换上传、生成缺失音频和单句强制重生成。上传限制为 8MiB、30 秒，PCM WAV（8/16 bit，单/双声道，8–48kHz）。暂不接收 MP3；请先转成 WAV。
- 生成必须经过管理员的费用确认；现有音频（含自定义上传）默认复用。每个请求有幂等 ID，进行中的同一句生成互斥，失败或重启中断不自动重试。失败请求可能已被服务商计费，重试前先检查后台状态。
- 客户端没有 API Key，也没有任何触发生成的权限。客户端只访问公开只读的目录和音频接口。

## 存储与更新协议

音色定义、当前音频映射、生成任务和音频字节均保存在现有服务器 SQLite 数据库的 `voice_*` 表。音频以 SHA-256 寻址并去重，不改变原业务表。替换音频后旧版本仍保留，便于已有客户端和已付费资产复用；软停用音色不会复用其编号。新增音色编号从 6 起，0 为LOL默认，5 为 Windows 本机语音，原四个编号保持不变。

- `GET /api/voice/catalog`：目录、音色标签、稳定编号、默认映射、台词音频的 SHA-256/大小/URL；支持 ETag / If-None-Match / 304。
- `GET /api/voice/audio/<sha256>.wav`：不可变音频资源，长期缓存。
- 管理接口 `/admin/api/voices`：列表、添加/编辑、上传、生成和任务查询，必须认证，修改必须带 CSRF。
- 新安装默认静音。授权后即同步目录，约每 60 秒复查；只有勾选播报才预取所选音色的固定台词。默认音色为LOL音效播报，所有展示风格一致；语音播报与全屏特效默认关闭，已有显式选择不强制覆盖。
- 客户端缓存位于 `%LOCALAPPDATA%/DNFGameCapture/voice-cloud/<服务器哈希>/`，服务器之间隔离。文件写入前校验大小和 SHA-256，再原子替换；取消勾选不再发起音频下载，正在进行的下载会尽快中止。
- 新版本只下载变化的音频；已经随客户端打包的旧 WAV 若与服务器哈希一致，直接导入本地缓存，不再下载。
- 离线保留最后有效目录和音频。无可用缓存时使用 Windows 免费离线语音，不调用豆包；不播放已被服务器更新替代的旧打包文件。目录加载前仅提供默认和 Windows 选项。

## 服务器部署（需管理员执行）

准备部署包不会自动上线、修改生产数据库或上传正式服。本次经用户明确授权，另行补生成了28条胜利语音；下列测试与导入步骤均不调用付费 API。

1. 备份原服务及 SQLite 数据库（在线服务请使用 SQLite backup，或停服后备份；不要只复制正在写入的主 DB 而漏掉 WAL）。
2. 在服务目录执行 `npm ci`、`npm run build`，部署新的 `dist`，保留原数据库和认证配置。使用单个 Node 服务实例；启动时会将中断的生成任务标为失败，避免重复扣费。
3. 将已有 `web前端/voice/` 下五个目录共 140 个 WAV（112条TTS，包括保留的84条旧音频与28条新增胜利语音；LOL 28个槽位复用7段网站素材） 拷贝到服务器临时导入目录。无需重新生成。
4. 先离线校验，再明确导入到原数据库：

```sh
node dist/import-voices.js --from /srv/import/voice
node dist/import-voices.js --from /srv/import/voice --database /srv/dnf/cloud-match.sqlite --apply
```

导入可重复执行，同哈希跳过；默认拒绝覆盖已修改的槽位。如确需覆盖，另加 `--replace`（旧音频版本仍保留）。导入工具不读取 API Key，不访问网络。建议停服导入，核对数据库路径后再启动服务。`--apply`要求目标数据库已经存在，防止路径写错时新建空库。

5. 后台若需要生成新音频，由管理员在服务环境中配置 `DOUBAO_TTS_API_KEY` 和 `DOUBAO_TTS_APP_KEY`，不要提交到源码或发送给客户端。仅自定义上传／复用旧音频不需要配置这些变量。
6. 反向代理转发公开 `/api/voice/` 到原客户端端口；后台 `/admin/voices` 和 `/admin/api/voices` 仍只走受保护的管理入口。管理上传的代理 body limit 至少 8MiB。推荐全程 HTTPS，尤其 Basic 认证的后台。
7. 同步发布新的 EXE 与完整的 `web前端/` 静态界面（含 `kill.css`、`kill.html`）。旧客户端不具备服务器目录同步能力。

音频永久保留，当前总音频资产上限 1GiB，单音色库上限 256。定期备份整个数据库；本次不提供自动删除旧资产，避免删除已付费音频。
