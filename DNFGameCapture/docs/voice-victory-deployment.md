# 云端音色 + LOL 音效 + 左侧七分胜利：合并升级包

本包仅供管理员手动升级，**尚未部署或替换现用程序**。保留既有版本号，不沿用项目中版本不一致的旧自动发布脚本。

## 包含内容

- `server/dist/`、`package.json`、`package-lock.json`：已编译的服务器更新；不包含 node_modules、数据库、生产配置或密钥。
- `assets/voice/`：五个音色、每个28个固定台词槽位，共140个 WAV。四个原有音色112条（原84条完整保留，新增胜利语音28条）；`LOL音效播报`28个槽位复用7段下载素材。服务端按SHA-256去重，客户端只在开启播报后下载所选音色。
- `client-update/`：隔离构建的 Release/x64 EXE、WebView2Loader（若构建目录含该文件）和完整的顶层静态界面文件。这是**现有安装升级包，不是完整安装器**。
- `docs/`：云音色说明、LOL来源及限制、验证记录。
- `SHA256SUMS.json`：逐文件哈希与大小，可用于部署前比对。

## 行为

- 新增音色名严格为 **LOL音效播报**。0=随风格，1–4=原音色，5=Windows；LOL动态分配新编号，不挤占既有自定义音色。
- 实际显示在左侧的队伍从低于7分升到至少7分时触发胜利，红/蓝均可；翻转只改变左右映射，不产生虚假胜利。页面初次加载、刷新或重开时已有7分不会补播。
- 同一比赛仅一次；双方归零后重新武装。隐藏、总特效关闭或胜利事件关闭期间发生的事件不延后补播。若胜利事件关闭，正常终局击杀/AK仍按原规则处理。
- 胜利优先于同批最终击杀/AK；文字特效和语音跟随现有开关、延时、时长及播放窗口归属。默认语音仍关闭，OBS浏览器源不触发本机语音。
- 9种界面对应7种胜利话术：DNF/玻璃「胜利！」；国风「大捷！凯歌还！」；经典/像素「Victory!」；霓虹「Victory! Mission complete!」；烈焰「烈焰凯旋！」；赛事「比赛胜利！恭喜！」；寒冰「冰封全场，凯旋而归！」。LOL全部使用下载的Victory。
- 用户关闭全屏特效窗口（含Esc）后，将全屏开关保存为关闭并广播更新管理面板；程序内部暂时隐藏窗口不改变保存选择。

## 服务器：管理员手动执行

1. 确认维护窗口、现有服务目录与**实际数据库绝对路径**。备份程序、环境配置及整个SQLite状态。停服后备份，或用SQLite backup；不要漏掉仍有事务的 WAL。保留现有许可证、管理口令、签名密钥、服务定义和数据目录。
2. 停止原服务，把包内 `server/dist` 和两个 package 文件更新到原服务目录，**不要清空整个目录**，不要覆盖原生产配置与数据库。不要上传客户端EXE到服务目录，也不要使用 `rsync --delete` 清理生产目录。
3. 使用原服务兼容的Node运行环境，在服务目录执行 `npm ci --omit=dev`。包中没有跨平台原生依赖；better-sqlite3需要在目标服务器安装。本包无需重新 TypeScript 编译。
4. 将 `assets/voice` 复制到服务器的临时导入目录。先校验再明确导入。下面路径是占位示例，必须替换成真实路径：

```sh
node dist/import-voices.js --from /absolute/import/voice
node dist/import-voices.js --from /absolute/import/voice --database /absolute/existing/cloud-match.sqlite --apply
```

首次命令只校验140个WAV；第二个命令才写入指定的**已存在**数据库。不会自动新建空数据库，也不会调用TTS。再次执行会复用同哈希资产；若槽位已被管理员换成别的音频，默认拒绝覆盖并回滚整批写入。不要随意添加 `--replace`；只有明确希望用包内内容覆盖自定义槽位时才使用。

5. 仍用原环境配置、原端口与原服务定义启动。公开入口需要代理 `/api/voice/catalog`、`/api/voice/audio/`；声音管理 `/admin/voices`、`/admin/api/voices` 只放在受保护管理入口，沿用Basic认证和CSRF。不要将后台开放到公开客户端端口。
6. 登录管理后台确认五个音色、每个28个可试听槽位；检查新目录的LOL名称、既有自定义音色编号、静态音频可访问。导入这些已生成资产不需要TTS API密钥。
7. 仅当管理员将来主动生成新台词/音色时，才在服务环境配置API凭据并在后台确认费用。不要把API凭据写入前端或升级包。

回退前先停止服务，恢复同一份备份的程序及数据库状态，再按原服务定义启动。保留本次新增的已付费音频备份，避免回退后误重复生成。

## 客户端：管理员/用户手动升级

1. 退出原程序，备份原EXE与`web前端`。
2. 用 `client-update/` 中的同名文件更新现有安装目录；保留原配置、数据库、许可、用户背景图、字体和其他运行依赖。不要删除整个安装目录。
3. 手动启动更新后的程序，连接已升级的服务器。声音列表同步后，可选择 **LOL音效播报**；勾选「语音播报」才会下载与播放。首次下载完成后可复用本地缓存。
4. 人工验收：红左6→7；翻转后蓝左6→7；仅翻转/刷新/重开不补播；双方0→0后下一场可再触发；关闭全屏窗口时管理开关跟着关闭；总特效与胜利事件关闭时不补播；语音未勾选时保持静音。
