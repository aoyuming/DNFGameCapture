# 本地选手库

## 数据位置

- 常规客户端：`%APPDATA%\DNFGameCapture\player_library.db`。
- 当前服务器授权测试模式（`[CloudMatch] ServerAuthV2=1`）：`%APPDATA%\DNFGameCapture\test\player_library.db`，与常规库隔离。
- SQLite 已静态编译进 EXE，不需要用户安装数据库或额外的 SQLite DLL。

数据库保存选手实体、关联名称、游戏 ID 和本地归并记录。同类 ID 的规范化键唯一，多名称或多候选归属通过关联表引用，不重复保存完整 ID 文本。不同大小写、不同职业继续按原有存储规则区分。

## 升级与兼容

首次运行时，在后台读取 EXE 旁的 `alias_db.ini` 和 `player_identity_groups.json`，备份为带时间戳的 `*.migrated.bak`，校验成功后安装数据库。迁移不会删除原文件；失败时保留旧库，只读加载可用的旧数据。

数据库建立后，它是唯一真实数据源。修改选手或游戏 ID 会先提交数据库，再刷新界面，并兼容导出 `alias_db.ini`。直接用记事本编辑该 INI 不会反向导入数据库；请在软件中编辑。兼容 INI 中仍可能有重复列表，这是给旧格式使用的导出，不参与新数据库的去重索引。

保留迁移备份，不要用旧客户端同时修改同一目录的数据。回退测试时应先关闭新客户端，另建旧版目录并使用迁移备份，不要直接覆盖正在使用的数据库及其 `-wal`、`-shm` 文件。

## 编辑与识别

- 别名共用选手实体的游戏 ID，规范化索引避免重复存储。
- 自动归并按去重后的交集判断：共同游戏 ID 至少 5 个。未达到 5 个相同游戏 ID 不单独触发归并；未达到阈值的重叠保留确认建议。
- 有忽略记录的名称不会被新候选组直接重新归并；归并后的新增 ID 在拆分时需要指定保留给哪个名称。
- 保存、归并与云端合并在单独工作线程执行。前端只在库版本变化时接收完整库；编辑提交带版本号，旧版本命令不会覆盖新数据。
- OCR 只使用场上八人的游戏 ID，并保留原有模糊匹配、多帧融合、大区和职业辅助判断。开始监控前每名上场选手必须配置游戏 ID。

## 云端

服务器 v2 上传和拉取直接使用 `entities`，包含 `entityId`、`names`、`gameIds`，不包含本地身份组恢复元数据。旧云函数仍使用原有扁平游戏 ID 库格式。

v2 拉取按实际请求地址分别记录云端版本，拒绝过时快照。重复拉取相同内容不增加本地库版本；身份归属冲突时保留本地数据并报错，不强行覆盖。

主播一次同步和实时同步成功后，名称及游戏 ID 会提交给本地数据库线程进行追加合并；比分变化和座位顺序变化不会重复触发相同的库导入。预览、取消不会写库。场上名称、比分、战绩保持同步后的结果，归并只统一选手身份与 ID 集合。

已接受的不同选手批次按顺序写入，不被后续快照丢弃；正常退出先写完待保存数据。失败不会被当成已提交，后续新收到的同步可以重试。

测试服 v2 选手库的单组名称和游戏ID列表分别允许最多10,000项，不再沿用扁平库时期32名称/256ID的单组限制；总请求及公共库仍限制为256 KiB，超过时明确拒绝且不部分保存。该调整不放宽比赛快照限制。

新版不发送或使用冒险团字段，旧请求中的该字段被忽略。本地库和服务器旧数据库在事务迁移中清理该类数据，保留选手、别名和游戏 ID。手动归并保留；本地旧自动组有完整原始快照时按游戏 ID 规则重新计算，依据不完整或已被编辑的组保留并提示人工复核。部署顺序为先更新测试服，再更新参与测试的客户端；旧云函数、OSS 和正式服不需要部署变更。

测试服后台的 `/admin/library` 使用原三栏共享库管理台布局，但接口已改为服务器数据库，不连接 OSS。它与 `/admin` 共用管理身份校验和 CSRF 保护。

## 验证

- `scripts/check-player-library-core.ps1`：迁移、事务、编辑、索引与异常回滚。
- `scripts/check-player-library-integration.ps1`：主窗口异步接入检查。
- `scripts/player_library_migration_audit.cpp`：将真实库复制到临时目录后核对名称、ID 归属和索引，不改动输入源。
- `scripts/check-player-library-migration.ps1 -Sources <INI路径>`：编译并执行真实库副本迁移审计。
- `scripts/check-player-identity-ocr.ps1`：场上游戏 ID 候选、缓存生命周期和临时移除 ID 回归。
- `node --test scripts/player_library_web_test.js`：前端版本过滤、只读回退、草稿与编辑命令。
- `node scripts/player-library-preview.cjs`：只读假数据预览，绑定本机 `127.0.0.1:58634`，不连接云端。
