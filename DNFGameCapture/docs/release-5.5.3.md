# 5.5.3 · 主播工具

## 变更

- 主操作栏原「展示页面」「特效管理」合为一个「主播工具」按钮。
- 三个页签：**展示与输出 / 特效管理 / 声音管理**。
- 展示与输出：原展示窗口的显示/隐藏开关，状态跟随原生窗口；不移动比分、按键等其他展示窗口。显示/隐藏使用明确目标状态命令，重复请求不会反向切换。
- 「更多」中的「选人顺序」改名为 **txt输出选人顺序**，移至展示与输出，沿用原设置键和TXT输出行为。只影响击杀.txt中的名字前缀，不改变展示样式。
- 特效管理：保留原文字、击杀、全屏、事件、延迟、时长和大小设置，关窗后的全屏开关同步保持有效。
- 声音管理：保留默认静音、播报音色和缓存状态；试听新增独立UI风格、音色、内容选择及停止按钮。UI对应原展示页面的9种风格，而不是主窗口的3种配色。
- 试听默认跟随直播UI与音色，也可指定组合。不修改 `layout.skin` 或 `layout.fxVoice`；仅点击播放时请求所选组合。切换试听会取消旧的排队播放；停止按钮停止当前语音并取消排队请求，不改设置。
- 原有总特效和语音开关仍约束试听，页面会提示需要开启哪个开关。缺少所选音频时下载服务器现有音频或沿用原免费离线回退，不触发付费生成。
- 应用版本5.5.3；EXE FileVersion/ProductVersion为5.5.3.0，安装器定义及前端版本标记同步。历史5.5.2设置迁移代码不改动，避免再次重置用户设置。

## 升级

若已部署上一版云音色服务器和音频，本次只需退出客户端、备份后更新包中的 `client-update` 同名文件；无需再次导入或生成音频。

如果尚未部署上一版：本合并包保留此前验证的服务器与140个音频槽位，按 `docs/voice-victory-deployment.md` 完成服务器更新、离线校验及导入，再升级客户端。包不含生产配置、数据库或密钥。LOL素材提示音与复仇替代说明仍适用，见来源清单。

这是现有安装升级包，不是完整安装器。保留原配置、数据库、许可及其他依赖；需要回退时退出程序并恢复原EXE与配套静态文件。不要清空安装目录，不要把用户配置替换成测试配置。
