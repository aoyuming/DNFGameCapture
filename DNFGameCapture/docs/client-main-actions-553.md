# 5.5.3 客户端更新包 · 主界面分组和抽签

## 本次改动
- 「分组和抽签」从「更多」移至主界面底部操作栏，紧挨「开始识别」，常驻显示。
- 大号骰子图标和高对比高亮按钮，三种主题分别配色；窄窗口自动换行，避免操作按钮互相挤压。
- 仍使用原有分组/抽签工具：读取场上名单、随机分组、抽签、应用到红蓝、复制及重置逻辑不变；保留原有监控及实时同步限制。
- 保留5.5.3已有主播工具、TXT选人顺序、LOL默认音效和语音/全屏默认关闭行为。已有保存设置不强制重置。

## 如何更新
这是**现有客户端的更新包，不是全新安装器**。
1. 完全退出原客户端，备份原程序目录。
2. 把包内 `client-update/` 的全部内容复制到原客户端目录，覆盖同名文件；`web前端/` 必须一并更新，不能只换EXE。
3. 保留原有配置文件、数据库、语音缓存及其他运行依赖，不要删除原目录后重新解压。
4. 自行启动客户端，主界面「开始识别」右侧即可看到「分组和抽签」。

此包**只更新客户端**，不包含服务器代码、部署脚本、音频库或私密TTS环境文件，不需要上传服务器或运行服务器升级命令。
此前LOL音频修复包及其服务器部署流程独立保留，本次不代替、不执行它。
没有更改/重新下载/生成音频；本次付费TTS调用为0。
