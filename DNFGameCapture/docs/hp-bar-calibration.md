# 血条百分比检测区域微调

## 入口

打开 C++ 捕获预览窗口，点击 **点位校准**，再点击预览底部新增的 **血条微调**。
这是原生非模态面板，可同时观察原有预览里的血条框和血量百分比。

## 调整

- 选择左侧或右侧血条。
- 选择整体移动、左上角或右下角，再使用方向按钮；步长可选 1、5、10 像素。
- 面板内非输入框焦点下支持方向键；按住 Shift 为 10 像素。
- 直接输入左 X、上 Y、右 X、下 Y 后，按 Enter 或点击“应用坐标”。
- 单位是**裁剪后的原始捕获画面像素**，不是桌面坐标，也不是缩放预览像素；原点是捕获画面左上角，右/下边界不包含在采样区域中。
- 输入越界、边界颠倒、区域太小都会被拒绝；方向微调在边界自动停止。
- 捕获分辨率改变时，会清除尚未应用的像素输入，按原有归一化区域重新显示新坐标。

## 保存与取消

- “应用坐标”立即影响预览与检测，但尚未写入配置。
- “保存并退出”复用当前点位校准会话的保存操作，写入 EXE 目录的 `config.ini` 中 `[HpBar] LeftRect/RightRect`；同一会话内的死亡 X 调整也会一起保存。
- “取消并退出”、Esc 和关闭面板恢复进入本次点位校准前的快照（包括同一会话内的死亡 X 和血条调整）。
- “恢复当前侧默认”只恢复所选血条，不重置死亡 X；需要保存才持久化。
- 仍支持原来的预览内拖动、9/0 选择血条以及方向键微调，数值面板同步更新。

## 识别逻辑

没有新增“单点即满血”判定，也没有改变现有颜色分类、有效行中位数及 98% 补正为 100% 的规则。
原有检测仍读取调整后的左右矩形中间一半高度，避开血条上下边框。
未开始计分监控时，只要处于校准模式并有有效捕获画面，也会更新血量百分比。

## 验证

纯 C++ 几何回归测试：`scripts/hp_bar_calibration_test.cpp`，不依赖 MFC，可用 C++17 编译器编译执行。
测试覆盖原图 1/10 像素步长、移动和缩放边界、最小矩形、四种分辨率、非法输入与 INI 六位小数往返。

Windows 人工验收：
1. 选择捕获源，在未开始监控时进入校准，确认左右百分比会更新。
2. 同时测试拖框、输入坐标和方向按钮；缩放预览后，一次微调仍只改变原图 1 像素。
3. 在坐标输入框输入含 1/9/0 的数值，确认不会被主窗口快捷键抢走。
4. 分别测试左上角/右下角到达边界、错误数值、切换血条和捕获分辨率变化。
5. 验证保存重开、取消恢复、当前侧恢复默认，以及保存失败时面板保留未保存状态。
