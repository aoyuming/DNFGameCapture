# 5.2.1 正式版

## 修复内容

- 修复 V2 自动同步先提交旧本地快照、后导入公共身份，导致其他主播投稿大量名称归属冲突的问题。
- 自动同步现在先拉取公共库并提交 SQLite 事务，再从已发布快照重建投稿，确保沿用公共 `entityId`。
- 公共库导入存在真实归属冲突时暂停自动投稿，避免把不完整身份继续送入审核区。
- 导入期间关闭自动同步、退出客户端或切换授权作用域时，不再启动过期的投稿请求。
- 增加 `AliasDbSync/PullBeforePushVersion=1`，升级客户端会立即执行一次修正后的同步流程，不等待旧七天检查点。

## 发布操作

1. 在审核后台驳回升级前产生且“匹配公共实体 0”的异常投稿，不要整批审核通过。
2. 确认现有 5.2.0 正式服务器的 V2 选手库接口正常；本次没有服务端代码变更，无需重新部署服务器。
3. 上传 `update_v521.zip` 后，再发布对应的 `update_v2.txt`。当前只生成了本地文件，尚未上传 OSS 或修改线上更新清单。
4. 主播升级后让客户端完成首次自动同步；流程会先吸收公共身份，再仅提交本地新增内容。
