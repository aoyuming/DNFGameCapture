# 5.5.3 客户端修订包 r3 · 单行按钮栏

此包替代此前Main-Actions/r2客户端更新包，EXE版本仍为5.5.3.0。

## 本次改动
- 按用户标出的中间空位摆放「分组和抽签」：在「专业模式」之后、右侧开关与「更多」之前。
- 删除r2的上下两排/多行按钮网格，操作栏保持单行。按钮统一42px高，右侧两个开关沿用原来的上下小开关布局，但整组不再落到第二排。
- 删除人为预留的宽度，用真实内容尺寸和中间剩余空间排版；较窄窗口减小间距和装饰图标，不将整组操作换行。
- 极窄可用区域小于620 CSS像素时，仅左侧操作条可横向滚动，仍不换成上下两排；正常测试窗口960–1600 CSS像素范围全部按钮和文字可见。
- 保留r2姓名提示修复：打开分组时不自动显示姓名候选，编辑名单后才匹配显示，失焦或Esc收起，选取候选功能不变。
- 现有声音功能保持不变，未增加逐事件音色绑定或新试听列表。

## 更新步骤
这是已有客户端的更新包，不是全新安装器。
1. 完全退出客户端，备份原程序目录。
2. 把 `client-update/` 下全部内容复制到原客户端目录，覆盖同名文件。
3. **EXE与`web前端/`一起更新**，不要只换EXE；保留原配置、数据库、语音缓存及其他运行依赖。
4. 自行启动客户端确认新的单行按钮排列。

无需上传服务器或执行服务器部署命令。本包不含服务器代码、音频、环境配置、私密TTS文件。
本次未生成、下载或修改音频，没有付费TTS请求；已保存的语音和全屏开关不强制重置。
先前LOL音频修复包及对应服务器部署流程独立保留，本包不代替或执行它。

- 等效125%/150%缩放逻辑视口检查；极窄横向滚动不改变单行布局。
- 带预填名单的提示框测试，候选选择、失焦/Esc、重开、分组/抽签、监控拦截检查通过。

- 未替换或启动现用程序，未修改/部署服务器。
