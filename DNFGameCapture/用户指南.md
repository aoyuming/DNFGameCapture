# DNF 自动人头记分用户指南

这份指南面向实际使用者，按比赛使用顺序说明怎么启动、授权、填选手、开始监控和接入 OBS。

## 1. 使用前准备

请先确认这些条件：

- Windows 电脑。
- 已安装 Microsoft Edge WebView2 Runtime。
- 软件同目录有 Umi-OCR，或能手动启动 `Umi-OCR.exe`。
- 有可用的授权 CDK。
- 如果要使用 `打补丁红蓝判断` 死亡 X 算法，EXE 同目录需要有 `sprite(击杀大XX).NPK`。

建议先关闭游戏再安装死亡 X 补丁；如果游戏已经运行，复制补丁后也需要重新上游戏才会生效。

## 2. 首次启动

1. 启动 `DNFGameCapture.exe`。
2. 在 Web 记分窗口点击 `授权`，输入 CDK。
3. 确认授权显示正常后，选择要捕获的目标：
   - 默认会找 `地下城与勇士：创新世纪` 窗口。
   - 也可以从目标下拉框选择指定窗口或摄像头。
4. 选择捕获引擎：
   - `自动选择`：推荐，优先 WGC，失败后走兼容模式。
   - `WGC 硬件加速`：画面更稳，适合支持的系统。
   - `PrintWindow 兼容模式`：WGC 异常时使用。
5. 点击底部的输出目录栏，可更改 TXT 输出目录。

## 3. 填写选手和小号

界面分为红队和蓝队，每队 4 个位置。每个选手都要填写主号，并至少绑定一个小号。

小号规则：

- 主号主要用于显示和归属，不直接参与 OCR 名称匹配。
- 上场选手没有小号时，不能开始监控。
- 真实 ID 少于 3 个字符时，建议补充大区或职业，否则容易误识别。
- 推荐小号格式：
  - `真实ID`
  - `大区真实ID`
  - `真实ID#职业`

在选手输入框旁打开小号菜单后，可以：

- `绑定新小号`：给当前主号添加小号。
- 修改小号：同步修改永久小号库。
- 临时解绑：只在本次场上隐藏，不从底层库删除。
- 永久解绑：从小号库彻底删除。

## 4. 云端小号库

- `同步云端库`：从公共小号库拉取数据并合并到本地，不会删除本地已有小号。
- `推送本地库`：把本地小号库变化提交到云端待审核区。
- 管理员可用隐藏直写模式直接写公共库；普通用户不需要使用。

如果刚同步过云端库，程序会记录基线，用来判断之后本地库有哪些新增或删除。

## 5. 开始比赛监控

1. 确认红蓝队选手和小号都填写完整。
2. 确认 Umi-OCR 已启动；如果没启动，程序会尝试自动拉起。
3. 选择死亡 X 算法：
   - `大X颜色个数判断`：不需要补丁，通用。
   - `打补丁红蓝判断`：需要安装 `sprite(击杀大XX).NPK`，通常更依赖补丁后的红蓝特征。
4. 点击 `运行` 开始监控。
5. 再次点击可停止监控。

监控中程序会自动识别击杀、死亡、AK 和总比分，并刷新 Web 界面与 TXT 文件。

## 6. 常用操作

- `翻转红蓝`：交换左右显示和输出方向，适合 OBS 画面左右队伍与软件相反的情况。
- `最近识别`：查看自动识别记录，可撤销或恢复某条识别战绩。
- `C++日志`：查看底层识别、同步和错误提示。
- `清空红队` / `清空蓝队`：清空对应队伍选手。
- `重置战绩`：清空击杀、死亡、AK 和总比分。
- 选手行可拖动/交换，方便调整位置。

## 7. OBS 接入

在 OBS 中添加文本源，读取输出目录里的文件：

- `比分.txt`：总比分，例如 `3-2`。
- `左侧人头.txt`：左侧队伍每名选手的击杀/死亡/AK。
- `右侧人头.txt`：右侧队伍每名选手的击杀/死亡/AK。
- `击杀.txt`：左右两边的击杀简表。

如果使用了 `翻转红蓝`，这些输出会跟随翻转后的左右方向。

## 8. 常见问题

### 授权失败或过期

重新点击 `授权` 输入 CDK。CDK 会和当前机器绑定，如果提示已绑定其他机器，需要联系管理员处理。

### Umi-OCR 未运行

程序会尝试自动启动。若仍失败，请手动打开软件同目录下的 `Umi-OCR.exe`，等待 OCR 服务启动完成后再点 `运行`。

### 检测不到游戏窗口

确认 DNF 窗口标题为 `地下城与勇士：创新世纪`，或在目标下拉框里手动选择正确窗口。也可以选择摄像头/采集卡作为输入源。

### WGC 捕获失败

把捕获引擎改为 `自动选择` 或 `PrintWindow 兼容模式`。WGC 依赖系统和窗口状态，失败时兼容模式更稳。

### 打补丁红蓝判断无法启动

确认 EXE 同目录有 `sprite(击杀大XX).NPK`。程序会尝试找到 DNF 的 `ImagePacks2` 目录并复制补丁；找不到时，可以在 `config.ini` 的 `[Settings]` 下写入 `ImagePacks2Path`。

### 开始监控提示选手信息不完整

检查每个上场选手是否至少有一个小号。2 字短 ID 还需要补充大区或 `#职业`，例如 `某ID#剑魂`。

### 云端库同步和推送有什么区别

`同步云端库` 是从公共库拉取并合并。`推送本地库` 是把本地变化提交到云端待审核，不会立刻变成公共库，除非管理员审核通过或使用管理员直写。
